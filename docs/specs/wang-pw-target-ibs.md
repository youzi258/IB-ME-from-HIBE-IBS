# Wang–PW 目标规模研究 IBS 契约

**2026-10-20 用户确认的比较口径：** 本项目暂按约115位量子安全的工作假设开展实现与比较；当前配置的具体攻击成本尚未复核。

本文约束 `wang-pw-target` / `WangPW-target-s0-4-v1` 独立目标规模实现，与旧 `wang-pw` / `WangPW-research-v1` 的
q=17 小参数后端并存，不改变其对象格式或历史反例。目标规模配置以
`s0=4` 为主档；`s0=2` 的有限实例论证不在本任务范围。
本文约束实现和验收。2026-10-21 用户已确认目标规模实现交付完成；具体已运行阶段、
跨版本复用和历史证据边界见[完整交付说明](../research/2026-10-19-wang-pw-target-s0-4/PUBLICATION_zh-CN.md)。

## 1. 算法、参数与声明

- 基础算法：Wang Figure 4 IBS；外层使用 Pan–Wagner Figure 5 的身份盐、
  消息盐转换。
- 采样实现须明确区分 G-trapdoor 的生成、委派 SamplePre 与签名 SamplePre。
  用 G-trapdoor 转完整整数核基、再执行 GPV/Klein 采样时，记录为该实现
  路线，不冒称已经实现 MP12 Algorithm 3 的 perturbation sampler。
- `s0` 按 `exp(-pi*x^2/s0^2)` 的宽度解释。标准差为
  `s0/sqrt(2*pi)`；原数值原型把 4 当作连续正态标准差的实测不可直接
  作为该主档的采样或性能证据。
- 参数快照包含尺寸、模数、采样宽度、公开范数门限、盐长度、入口容量、
  有限采样与资源限制。所有对象绑定同一完整快照。
- 已完成的冻结 `s0-4` 主档按用户确认前提在当前registry登记为
  `security_claim=secure`、`backend_admitted=true`、`parameters_are_formal=true`。
  `debug-small` 和旧q17不继承该声明；历史Suite及原语wire中的旧字段保留兼容。
  约115位量子安全是项目工作假设，不是本次实测成本或NIST类别。

依照项目 AGENTS，以引用论文已有性质和参数条件为前提推进；不新增
完整安全归约、hybrid 或 s0=2 的有限实例证明任务。实际算法差异、
失败、采样精度与参数估计输入继续如实报告。

## 2. 委派方程与用户隔离

令 `w=n*ceil(log2(q))`、`m=m_bar+w`，公开根矩阵为
`A=[A_bar | G-A_bar*R]`。根秘密 `R` 仅属于发行者。

对外部身份及其固定身份盐执行 PW 身份转换后产生 `H1`，按列采样
用户陷门 `X`，必须满足：

```text
A*X = G-H1 (mod q)
F = [A | H1]
F*[X; I] = G (mod q)
```

用户只持有自己的 `X`、固定身份盐、外部身份、参数和公开根上下文。
不得把主陷门 `R`、主完整核基或能确定重建主陷门的材料发给用户。
旧 standalone 的相反符号 `R_x` 约定不能与上述 `X` 直接混用。

仅采样 `A*X=-H1` 并构造 `[B,X;0,I]` 的历史数值探针，不满足上述
G-trapdoor 委派关系；其方程探针不能替代完整用户 KeyExt 的验收。

Sign 在独立进程中只能读取用户对象和公开上下文；不能读取主状态、
调用 Setup/KeyExt，或借恢复流程补造缺失秘密。由公开 `A` 和已有 `X`
确定重建用户完整核基/QR 工作区属于确定性恢复，不产生新的用户密钥。

## 3. 哈希、随机源与验签

身份和消息使用规范长度前缀及独立域。身份转换绑定外部身份和身份盐，
消息转换绑定消息和消息盐；内层 H1/H2 绑定所选公开根及完整参数上下文。
禁止无长度拼接、随机生成 H1/H2 或跨根复用上下文。

生产使用系统 CSPRNG 或从新系统熵初始化的明确密码学字节流；固定种子
仅用于测试。随机源返回的类型和字节数必须检查，失败不能回退到 NumPy
默认 PRNG。连续正态后四舍五入的旧采样结果不能标作离散高斯结果。

Verify 只依赖公开对象，检查身份/消息绑定、签名上下文、规范维度、
非零向量、公开固定的整数范数门和 `F*z=H2(mpk,id,m)` 模 q 方程。
公开门限在 Setup 前确定并进入参数快照，不依据一次样本事后放宽。
方程和范数的整数计算须防止 int64 中间累加溢出。

## 4. 对象、容量与状态

公钥、主对象、用户对象和签名使用新版本及独立 kind，严格拒绝未知字段、
重复、截断、追加、错误尺寸、非规范整数和错误公开根绑定。解码前先检查
总预算和字段长度，不按不可信维度分配大矩阵；不同采样或格式版本不自动
回退。尺寸统计报告实际 wire 字节数，不以 NumPy 工作区尺寸代替。

用户 `X` 可用经范围门检查的紧凑整数表示；任何窄化转换必须先检查，
不得截断溢出值。完整矩阵基和浮点 QR 工作区不必进入持久用户格式。
大对象恢复不能重新抽取用户陷门或身份盐。存储中必须保留已发钥缓存、
失败墓碑和发布顺序，避免同一身份失败后偷偷重抽。

独立固定发行服务应按同一身份复用已发布的用户对象；写入/采样/校验
失败后明确阻断。主状态提交在密钥发布之前。锁与故障边界按当前
[传输与状态契约](transport-and-state.md)逐项说明，不声称跨机器事务、
恶意回滚防护或未验证的硬断电恢复。

原始五方法 `Backend.key_extract` 保持随机化发钥且不携身份账本，登记
如实使用 `persistent_identity_cache=false`。独立 `service.FixedIssuer`
在外层增加固定发钥策略；其成功/失败账本不冒充原论文算法。服务快照
使用独立 `WPTISS01` 二进制版本、排序身份和总计小于 4 GiB 的容量门；
默认目标档最多1个用户，debug档默认4个。容量预检不分配目标矩阵。
快照按组件流式读写，不拼接完整多 GiB 快照。恢复验证所有对象与同一
完整公钥和参数绑定；pending或失败状态阻断所有新发钥和重发。

## 5. 公共装配与验收

公共五方法保持 `setup/key_extract/sign/verify/load_signature`，上层只使用
对象公开接口，不读取矩阵或陷门。使用独立 selector/version，与旧 q17
后端共存，完整参数、对象解码器和签名编码进入 suite。

公共参数预设为 `s0-4`（默认主档）和明确非安全的 `debug-small`；唯一
签名编码为 `reference` 二进制格式。`s0-2`、旧 `research` 及未知格式
不能在本 selector 上自动映射。算法总录把两个 selector 归于同一条
Wang–PW 路线，不把更换规模或采样器计为新增 IBS 算法。

Discovery、容量计算及配置预检不得生成密钥、读取熵、编译 C 或写状态。
缺少 NumPy/SciPy/native 等执行依赖时明确报告并拒绝运行，不替换为旧
后端或 mock。native 路径由明确本机配置提供，不能从不可信 suite JSON
中指定可执行代码。

native 必须预先显式构建，并通过 `IBME_WANG_PW_TARGET_NATIVE` 指定；
预检只检查依赖和路径，加载器仍负责 ABI 和动态依赖校验。静态预检
通过不意味着已执行 Setup 或验证目标实例性能。

目标规模签名可超过默认 64 KiB Hybrid 载荷预算；完整组合必须显式选择
足够的载荷上限并先通过容量预检。底层 HIBE 仍仅加密 32 B seed，不要求
与 IBS 共享 n、q 或矩阵表示；BYTEAUTH 和两层身份顺序保持原规范。

复用已完成根时，通用 CLI 可经 `import-role` 导入已有规范组合公钥和
自己的组合角色钥，不持有 master，也不重新执行 Wang Setup/Extract。
原始二进制身份使用显式 `--identity-encoding hex` 表示，必须解码回
原字节，不能换成 Alice 或把十六进制文本当作另一身份。导入来源、
发布失败阻断和禁止新发钥遵守[公共规范](../../IMPLEMENTATION_SPEC.md)。
固定服务的管理导入、研究组合驱动与通用 CLI 实跑分别记账；小参数
通过不代替 n512 实跑，也不把导入解释成 CLI/服务完成过原始首发钥。

验收至少覆盖：诚实生命周期；用户独立签名；公开验签；错误身份、消息、
公钥；损坏签名；越界范数；截断、追加和错误版本；规范往返；固定发钥、
重启恢复及故障阻断；所选 HIBE 的真实组合。小规模检查与 n512 实测分列，
空执行、只做静态预检或复用历史回执不能记为目标实例已通过。

每次实测记录完整参数和版本、身份/消息长度、随机源、重复次数、
CPU/内存/软件、计时边界、中止与失败、对象字节数及峰值工作集。
功能和有限负例不是一般安全证明；参数估计使用最终公开门限及论文
映射的 SIS 输入，不能单独引用历史样本范数对应的 153.70 等数字。
