# 相关支撑材料阅读指引

作品编号：**CACR2026T4PMR7**

作品名称：**基于多类格困难假设的抗量子身份基匹配加密通用设计和优化实现**

本材料与37页作品设计报告配套。程序采用同一个 HIBE＋IBS 通用框架，报告的三个代表为 A：LATTE＋BNN/ML-DSA-44，B：LATTE＋SRGG PARAM-I compact，C：Lai C2＋Sageloli RSIS v3 PARAM-I。

Wang＋PW目标规模IBS也已完成并合入本包使用的主线快照。源码、实验驱动和测试已随程序收录，目标规模验收记录和集成结果另见[Wang-PW补充说明](Wang-PW补充说明.md)及`03_实验数据/07_Wang-PW目标规模/`。本补充不改变报告三代表，不将Wang历史分阶段记录拼入原十组合的同条件性能排名。

## 读数方法

1. 先看对应表中的机器、输入和重复结构，再看时间、尺寸和内存。
2. LATTE三种IBS对照、A/B同机对照分别使用各自三根数据；同根的多次warm操作不计为更多独立根。
3. Lai C2四组合是共享一个HIBE根的单次观测；Luo组合来自另一批CLI记录。两批条件分别保留。
4. 优化批次的开／关对照、Luo控制随机流补充试验、C单根会话摊销分别记录；不把准备后的解密时间代替首次总成本。
5. 异机复现中A/B完成一次整套命令矩阵；C保留原超时历史和同根拆分阶段。原始结果没有改写为新增性能样本。

三组当前采用既定论文参数与项目已完成配置。参数来源、困难假设和随机预言机模型以报告及各原语引用为准；本包的文件检查与有限功能试验不增加安全证明或新的标准等级。
