## 复算验收

复用精确镜像 `sha256:09f183ad4facb5d1654732c672c86fe7d6d0a865a0f165974bfde1f95ba49fad`。公开材料只读挂载，容器使用 `--pull=never --network none --read-only`；wheel 校验后解压到临时 tmpfs，允许加载其原生扩展。结果写在材料目录之外，不安装软件或测量密码算法。镜像仍是 Sage10.7／Python3.12，原性能数据环境仍为 Ultra9／Sage10.9／Python3.13，二者明确记账。

- Windows PowerShell 5 启动器完成默认 Docker 自定义路径发现、全部复算及42项控制测试。
- Linux shell 启动器在 WSL 中通过真实 Windows Docker CLI 适配器连接同一 Linux Docker Desktop 引擎，全部复算及42项控制测试通过；不据此声称独立 Linux 主机验收。
- 两个入口的五个输出文件逐字节一致。CSV／Markdown也与PR90原件逐字节相同；JSON的所有参数、统计、尺寸、内存、次数与原件一致，只允许匿名审计身份及临时来源摘要不同。
- 原始PNG保持字节原样，复算PNG经解码及目视检查，尺寸为2720×2040和2720×1530。未覆盖原图。
- 55项定向测试在POSIX环境通过：6项本次用例、7项既有离线打包测试、42项PR90控制测试。Windows原生不提供SIGKILL，涉及POSIX进程组的原测试在POSIX运行，算法代码不为此改写。

[Windows复算收据](recompute-windows.json)、[Linux-shell复算收据](recompute-linux.json)记录同一输入绑定摘要。收据绑定 `source-records.json`，封包前重新核对全部绑定文件，拒绝验收后发生的内容变化。

## 匿名展示

仅提交副本的两份环境收据将参与者home路径显示为通用路径，一份测试XML的主机名改为通用名称。仓库原件、实际数值、源码／原生指纹不改。原文件SHA-256、显示副本SHA-256及转换类型随包提供。原 jobs、checkpoint、原表图均按来源核对。

原执行指纹包含原用户名，不能谎称匿名文件能散列得到同一指纹。复算在临时审计副本中重建匿名身份及checkpoint链接，继续执行原严格收据校验；所有统计字段须与归档原JSON一致。复算收据分别记录原执行指纹与匿名审计指纹，不把展示转换写成新的实验。原始输入前后均核对。
