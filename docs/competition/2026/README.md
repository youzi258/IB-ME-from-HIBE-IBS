## 纳入边界

两份 DOCX 按官方附件逐字节保存，不在其中填写作品内容，也不把 DOCX 当作报告的编辑源。当前作品维护[LaTeX 源稿](../../reports/2026-10-20-competition-rewrite/作品设计报告.tex)，直接导出 PDF；模板用于约束封面、A4 页面、页边距、页眉页脚和提交前检查。

官方压缩包还包含复赛团队名单。该名单含单位、教师和队员个人信息，与生成作品无关，因此不进入仓库；完整外层压缩包也不进入仓库。这样既保留必要的官方格式证据，也避免复制无关个人数据。

报告模板内嵌的 CACR 标志已逐字节提取到报告的`figures/cacr-logo.jpg`，校验值列在清单中。现稿不再沿用从往届优秀作品提取的标志。

## 提交前必须人工完成

官方通知要求匿名评审，作品设计报告和支撑材料不得出现单位名称、领队老师、指导老师或队员信息。系统在选题后自动生成作品编号；最终提交前必须把该编号同时填入报告首页和基本信息表，并按以下形式命名三个独立提交件：

- `编号-2026密码竞赛复赛作品设计报告.pdf`
- `编号-2026密码竞赛复赛相关支撑材料`
- `编号-2026密码竞赛审批及签字页`

当前[37页报告候选版](../../reports/2026-10-20-competition-rewrite/README.md)已经填写作品编号`CACR2026T4PMR7`，通过225项提交候选检查。配套[支撑材料审阅包](../../submission/2026-10-21/README.md)已整理源码、测试、配置、数据与截图。2026-10-21再次核对官网：三部分分别上传，支撑材料上限4 GB。

自动检查能排除已知占位符、机器路径、仓库账号和若干匿名字段，最终上传前仍需由团队确认PDF、支撑材料及元数据。当前源码MIT版权署名在提交副本中的匿名显示方式待著作权人确认，仓库原许可未改。审批及签字页按平台要求独立处理，不并入匿名设计报告，由团队完成真实审批与签章。
